# Public and private IP boundary

## Public competition repository

- Reference simulator, deterministic planner, typed schemas, state machine, safety checks, tests.
- Token Factory orchestration without credentials or captured prompt data from customers.
- Judge-mode-compatible API boundary and sample synthetic evidence.
- Reference MQTT/VDA5050-shaped messages containing synthetic identifiers only.

## Private production assets

- Customer maps, locations, orders, telemetry, incident video, employee information, and names.
- Device certificates, API keys, broker credentials, VPN settings, and network topology.
- Proprietary `qubridCompute` backend and optimization methods.
- Commercial adapters, PLC logic, safety-controller configuration, and OEM-specific details.

## Import rule

Nothing crosses from the private side unless it has an owner, a compatible license, a provenance
record, a pre/post-2026-08-26 classification, and a review showing that it contains no customer
or credential data. Public examples must use the synthetic HERO-002 world.

## Claims boundary

This is a mission-governance prototype verified in the demo environment. It does not replace a
certified robot safety controller, PLC, safety LiDAR, emergency-stop circuit, or site safety case.
